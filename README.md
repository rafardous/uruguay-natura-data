# Arapy

Catálogo de biodiversidad de Uruguay: app móvil offline y panel editorial privado.

- [App Expo/React Native](NaturaUY-source/README.md)
- [Panel editorial y publicación](NaturaUY-admin/README.md)
- [Operación y despliegue](NaturaUY-admin/docs/deployment.md)
- [Invariantes del proyecto](AGENTS.md)

PostgreSQL en Supabase es la fuente editorial. El catálogo activo contiene 948 animales y las 100 plantas seleccionadas; JSON y SQLite son derivados publicados. Las revisiones y especies archivadas se conservan para auditoría.
